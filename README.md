# victorgustavo.com

Site pessoal: quem eu sou, meus projetos e a página de download do
[Tasy Helper](https://victorgustavo.com/tasy-helper/).

HTML e CSS puros, sem build. Publicado no Cloudflare.

- `index.html` — início
- `tasy-helper/index.html` — download e instalação do Tasy Helper
- `style.css` — estilos das duas páginas
- `versao.js` — mostra a versão mais nova do Tasy Helper (API do GitHub)

Checagens: `node tests/checar.mjs`
